1Executive summary

Read this first. Every number in this report comes from the synthetic cohort generated by src/data/synthetic.py. No real patient data was used, because none of the public repositories in the blueprint carry Healthy / Glaucoma / Optic-Neuritis diagnosis labels. What was built

  • An end-to-end CAFN pipeline: dual-stream preprocessing → 3D ResNet(+SE) and multi-scale 1D CNN encoders → gated bidirectional cross-attention fusion → attention-pooled classifier, with unimodal auxiliary heads for multi-task supervision.
  • A synthetic class-conditioned MRI/VEP generator that closes the public-data labeling gap, plus a manifest-driven PairedNeuroDataset that accepts real data without other code changes.
  • A full training / evaluation / inference toolchain (CLI), explainability (Grad-CAM / Grad-CAM++, cross-attention heatmaps, P100 latency estimator) and 300 automated tests.

What the results actually tell us

  • solid The pipeline trains stably and reaches 97.9% validation / 99.0% held-out accuracy on synthetic data when given enough epochs (30 epochs, flagship run).
  • important On a fresh held-out set the VEP-only auxiliary head scores 99.0% and the MRI-only head 70.8%. The synthetic VEP latency alone separates the classes, so these results do not demonstrate that cross-attention fusion adds value. That question needs real data where each modality is only partially informative.
  • caution Short runs (smoke, demo: 4–10 epochs) ended at 33% accuracy. The best-checkpoint rule restores the epoch with the lowest validation loss, which in those runs was epoch 1 (untrained). See Training.
  • caution Three of the six references in Project.md have citation problems (wrong authors or arXiv IDs, or not verifiable). See Papers.

4Data we used (synthetic cohort) and preprocessing

Each sample is a paired 3D MRI volume and a 1D VEP sweep. Labels are balanced and deterministically shuffled; each sample is keyed by (seed, index) so it is identical across epochs, workers and runs. Training used 192 subjects (144 train / 48 val, stratified, seed 42) for the flagship run.

ClassMRI proxy (random location, radius 3–6 voxels)VEP P100 latencyVEP amplitude
0 · Healthy Controlellipsoid brain, no lesion100 ms ± 36.0 ± 0.8
1 · Glaucomafocal hypointensity (atrophy proxy)104 ms ± 42.5 ± 0.6 (amplitude loss)
2 · Optic Neuritis / CVIfocal hyperintensity (lesion proxy)138 ms ± 6 (latency delay)4.0 ± 1.0

The VEP waveform is a P100 Gaussian plus N75 and N145 troughs around the sampled latency. Two example raw cases are checked into data/raw/:

Preprocessing pipeline

MRI stream
  • RAS reorientation
  • 1 mm isotropic resampling, resize to 64×64×64
  • Foreground mask: percentile (v1) or Otsu + hole-fill + largest component (v2 option)
  • Normalization: min-max [0,1] or foreground z-score
VEP stream
  • Optional pre-stimulus baseline correction
  • Zero-phase 4th-order Butterworth band-pass 1–100 Hz
  • 50 Hz IIR notch (Q = 30)
  • Resample to 500 samples (250 Hz × 2 s), z-score
Doc/config mismatch: Project.md describes Otsu masking as the default, but MRIConfig.mask_method still defaults to "percentile", and the flagship checkpoint's stored config confirms it was trained with the percentile mask. Otsu is implemented and tested but was not used for the reported results.

Augmentation (train only): MRI flips, intensity scale 0.95–1.05, shift ±0.02, Gaussian noise σ = 0.01; VEP amplitude scale 0.9–1.1 and noise σ = 0.02. VEP is never shifted in time, because latency is the biomarker.

5Model architecture

Loss: fused CE + 0.3 × (spatial CE + temporal CE) by default; optional label smoothing, class weights, and Kendall-style learnable task weighting (UncertaintyWeightedLoss). Parameters: 1,955,140 (v2/v3 default) vs 1,803,305 (v1-style configuration).

Flagship run curves

Reading the curves. Training accuracy reaches ≥ 98% by epoch 2, but validation loss rises from 2.7 to 4.2 over epochs 1–3 and validation accuracy sits at 33% in epochs 1–2 (a single class predicted). Validation then recovers sharply: accuracy reaches 98% by epoch 7. This train/eval gap in the first epochs is consistent with BatchNorm running statistics not yet matching the weights, though we did not isolate the cause. The flagship converges: final train loss ≈ 0.07, best val loss ≈ 0.20 (epoch 26), and validation accuracy settles at 97.9% from epoch 12.

All runs compared

Finding — best-checkpoint rule can restore an untrained model. smoke (4 epochs) and demo (10 epochs) both had their lowest validation loss at epoch 1 because the early validation spike (above) can make later epochs look worse by loss. The restored best.pt then predicts one class for everyone (33% accuracy, macro-F1 0.167) even though demo reached 66.7% validation accuracy at epoch 8. Short runs should be judged on last.pt, or the selection metric changed to validation macro-F1 / balanced accuracy. Not fixed in this report.

What the ablation shows. After restoring the best checkpoint both models reach 98–100% validation accuracy, so on this easy synthetic task the final-accuracy gap is within noise. The difference is training stability: the v1-style model (constant LR, no clipping) is erratic — validation accuracy dips repeatedly (0.71 at epoch 12; 0.50, 0.75 and 0.48 at epochs 28–30) and ends at 0.48 — only its best-restore saves it. The v2/v3 model (warm-up + cosine decay, clipping, augmentation) stays between 0.94 and 1.00 from epoch 6 on. This supports the optimisation changes; it does not isolate the architectural ones (bidirectional fusion, positional encoding, attention pooling, SE), because they were changed together with the training recipe. A per-component ablation is still to do.

3D Grad-CAM (axial / coronal / sagittal)

Spatial × temporal cross-attention (64 spatial tokens × 16 latency bins)

Honest reading. (1) Cross-attention mass sits almost entirely on latency bins 0–2 (≈ 0–375 ms with 125 ms per bin), a range that contains the P100 window, but it is nearly uniform across spatial tokens, so it reflects which latencies matter rather than a region-specific map. (2) The Grad-CAM heat is strongest at the volume border and background corners, not on the lesion, so it should not be presented as lesion localisation. Neither map has been validated against ground-truth lesion masks, which the synthetic generator could supply.

What we can and cannot claim

  • can The engineering of a MRI + VEP cross-attention pipeline is complete, tested and reproducible, and the architecture choices mirror practices shown to help in the literature (cross-attention over concat/sum in CAMF; dual attention over single in DRIFA-Net).
  • can Our task combines modalities of different dimensionality (3D + 1D) that none of the verified papers address.
  • cannot Claim state-of-the-art or clinical accuracy. Real-cohort performance of CAMF-style fusion in the literature is in the 0.67–0.74 accuracy range for a hard binary psychiatric task; real glaucoma / optic-neuritis performance for our model is unknown.

14Limitations and recommended next steps

  1. Get labeled real data (clinician-labeled OpenNeuro/HCP subset plus paired VEP, or a clinical cohort). Everything else is secondary.
  2. Make the synthetic task harder (overlapping latency distributions, noisy/missing VEP, subtle lesions) so the fusion benefit and the v1-vs-v2 gap can actually be measured; add lesion masks to score Grad-CAM.
  3. Fix checkpoint selection to use validation macro-F1 / balanced accuracy, or train ≥ 10 epochs before enabling best-restore, so short runs cannot restore epoch 1.
  4. Investigate the epoch 1–4 validation spike (BatchNorm statistics, LR warm-up, momentum).
  5. Report variance: multiple seeds / cross-validation; with 48 validation subjects one error is 2.1 percentage points.
  6. Correct Project.md references (CAMF authors/venue, DRIFA-Net arXiv ID, verify Hao et al.) and the Otsu-default statement.
  7. Swap the placeholder skull-strip for HD-BET / SynthStrip before real MRI.
